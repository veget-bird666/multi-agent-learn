## 二、赛题简介

在数字化与智能化深度融合的时代，高等教育的个性化变革成为核心发展方向，同时也面临传统教学模式适配性不足的挑战。不同学生在知识基础、学习能力、兴趣方向上的显著差异，使得标准化教学难以满足个性化学习需求，部分学生存在知识吸收效率低的问题。

当前大模型技术迎来高速发展新阶段，以**通用大模型、多模态生成大模型（如SeeDance等）、AI辅助编程工具（如Claude Code等）** 为代表的技术体系，具备强大的自然语言理解、多模态内容生成、代码辅助开发及实时推理能力，为高等教育领域的创新升级带来全新契机。

**核心目标**：借助大模型技术体系，融合前沿AI技术，突破传统教育的技术与模式局限，构建高等教育个性化学习资源体系，开发智能学习智能体系统，切实满足学生的个性化、多模态学习需求。


## 三、赛题业务场景

### 核心问题
在高等教育学习过程中，学生普遍面临**学习资源繁杂无序、难以精准匹配自身需求且缺乏智能化、个性化学习指导**的核心问题。

### 具体表现
- 不同专业、不同学历水平的学生在面对海量课程资料、学术文献、学习辅助工具时，难以快速筛选出契合自身学习进度和能力的资源
- 课堂集体讲授模式无法兼顾每位学生的学习节奏与特点，导致学生在知识掌握和能力提升上存在明显差距
- 传统学习模式及基础的智能辅助系统，因缺乏多模态生成、多智能体协同等前沿AI技术的支撑，难以满足现代高等教育对培养创新型、个性化人才的要求

### 赛题要求
参赛团队构建**多智能体系统**，为学生打造专属的个性化资源学习智能体，并借助多智能体协作实现智能化、精准化的学习引导。系统需依托各类高等教育资源，融合多模态生成、代码辅助开发等技术，以**某一具体专业课程（如人工智能、计算机、电子信息相关等）** 为切入点，实现个性化资源的自动化生成与建设，根据学生个体情况提供定制化、多模态的学习内容，全方位辅助学生开展自主学习，真正实现"因材施教"的数字化落地。


## 四、基本功能需求

参赛团队需深入调研和研究新时代大学生的学习需求和痛点，融合前沿AI技术和工具，开发出能够高效生成个性化、多模态学习资源（如资源设计方案、PPT、题库、多模态视频/动画、实操案例、实践项目学习材料等）的智能体系统，实现提升学生学习效率、优化学习资源利用、增强学习效果的核心目标。

### 功能1：对话式学习画像自主构建（必须）

| 要求项       | 具体内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **构建方式** | 摒弃传统繁琐表单，支持通过**自然语言对话**自动抽取特征       |
| **对话内容** | 结合学生的专业、学习目标、学习历史等                         |
| **维度要求** | 构建包含**不少于6个维度**的动态学生画像（如知识基础、认知风格、易错点偏好等） |
| **更新机制** | 支持画像的**随学随新**                                       |

### 功能2：多智能体协同的资源生成（必须）

| 要求项       | 具体内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **架构要求** | 系统须体现"**多智能体**"架构设计                             |
| **交互方式** | 通过与学生的智能交互，大模型结合AI前沿技术和工具             |
| **输入信息** | 依据学生提供的专业、课程内容、知识短板、学习需求等信息       |
| **资源类型** | 须由不同角色的智能体协作完成**至少5种类型**的个性化资源生成  |
| **资源示例** | 专业课程讲解文档、知识点思维导图、不同类型练习题目、拓展阅读材料、多模态教学视频/动画、代码类实操案例等 |

### 功能3：个性化学习路径规划和资源推送（必须）

| 要求项       | 具体内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **工作机制** | 依托多智能体协同工作机制，整合系统生成的个性化资源           |
| **分析基础** | 结合大模型对学生专业、学习进度、知识掌握情况及学习偏好的深度分析 |
| **路径要求** | 为学生规划**科学、动态**的个性化学习路径，明确学习步骤和顺序 |
| **推送要求** | 基于画像实现学习资源的**精准推送**，涵盖文档、视频、题库、实操案例等多类型内容 |

### 功能4：智能辅导（可选加分项）

| 要求项       | 具体内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **触发场景** | 当学生在学习过程中遇到问题时                                 |
| **服务形式** | 系统提供**即时、多模态**的答疑解惑服务                       |
| **技术支撑** | 通过智能体的数据分析、大模型的知识支持，结合多模态生成技术   |
| **解答形式** | 提供详细的**文字解答、图解说明、短视频讲解**等多样化解答形式 |
| **目标**     | 实现针对性学习引导                                           |

### 功能5：学习效果评估（可选加分项）

| 要求项       | 具体内容                                                     |
| ------------ | ------------------------------------------------------------ |
| **数据来源** | 实时跟踪学生的学习行为、练习测试情况、资源使用反馈等数据     |
| **评估方式** | 依托大模型的数据分析能力实现对学生学习效果的**多维度、精准评估** |
| **动态调整** | 根据评估结果及时动态调整学习资源推送策略和学习计划           |
| **目标**     | 实现学习方案的**持续优化**                                   |


## 五、非功能性需求

### 需求1：界面与交互
- 系统界面**美观大方、简洁明了**，交互逻辑清晰
- 符合现代AI产品交互规范（如**流式输出、Markdown渲染、多模态内容卡片化展示**）
- 无明显功能与界面错误
- 可结合AI技术实现交互体验的智能优化

### 需求2：开源合规
- 若开发过程中使用开源项目、前沿AI工具/框架，需在提交文档的**显著位置标注名称、来源及相关协议要求**

### 需求3：内容安全
- 系统需具备完善的"**防幻觉**"与**内容安全过滤机制**
- 确保生成的学术内容**无事实性错误、无敏感违规信息**

### 需求4：响应性能
- 智能体核心功能的响应时间控制在**合理范围**内，保障学生的日常使用体验
- 多模态资源生成的响应效率需满足实际学习场景需求
- 如提供"**生成进度追踪**"或"**流式呈现**"机制，避免长时间白屏等待

参赛团队提交的文档需参考软件系统的标准文档规范，包括但不限于**系统开发说明书、测试说明书**等，且须满足以下核心要求：

- 需深入了解和研究新时代大学生的学习需求

- 两个层面的内容在文档中**条理清晰、逻辑连贯**
- 有充分的**数据与案例支撑**，全面体现系统的深度与广度
