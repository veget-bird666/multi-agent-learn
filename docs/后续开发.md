## 第一梯队：核心业务 Agent

### 1. path_agent — 学习路径规划
- **现状**：空模板
- **工作量**：约 1h
- **实现**：
  - 读 profile + knowledge_point → LLM 规划学习步骤
  - 返回 `learning_path`（steps 列表）
- **参考**：`profile_agent` 的 pattern（读 state → 调 LLM → 写回 state）

### 2. resource_agent — 多模态资源生成 ⭐
- **现状**：空模板
- **工作量**：约 2h
- **实现**：
  - 核心亮点：用 `Send()` 实现 Map-Reduce 并行生成 5+ 种资源
  - 资源类型：文档、思维导图、习题、代码案例、拓展阅读
  - 绑定工具：`generate_mindmap`、`generate_exercise` 等
- **参考**：自学项目 `LangGraph/map_reduce.py`

### 3. error_sim_agent — 错误模拟与纠正
- **现状**：空模板
- **工作量**：约 1h
- **实现**：
  - 展示典型错误 → 诊断原因 → 生成纠正内容
  - 可选：绑定 `search_knowledge` 工具查常见错误库

### 4. buddy_agent — 虚拟学伴
- **现状**：空模板
- **工作量**：约 1h
- **实现**：
  - 扮演水平略低的 AI 同学，让学生"教它"
  - 根据 knowledge_point 生成提问

### 5. curiosity_agent — 好奇心检测
- **现状**：空模板
- **工作量**：约 1h
- **实现**：
  - 分析 interaction_pattern（追问次数、停留时间等）
  - 区分好奇 vs 卡壳

### 6. reflection_agent — 后悔机制
- **现状**：空模板
- **工作量**：约 1.5h
- **实现**：
  - 遍历 teaching_decisions，评估效果
  - 如果表现下滑，标记 needs_rollback
  - 结合循环图实现回滚

## 第二梯队：增强功能

### 7. API 路由完善
- 补充 POST /chat 的初始 state（`history=[]`, `operation=0` 等）
- 确保流式输出与 Supervisor 循环图兼容
- GET /chat 保留直连 LLM 的快速通道

### 8. ChromaDB 群体记忆
- **现状**：`core/memory.py` 是空架子
- **实现**：
  - 初始化 ChromaDB
  - `save_experience`：存入教学经验
  - `query_similar_students`：查找相似学生
  - `query_best_method`：查询最佳教学方式
- **参考**：自学项目 `itheima/chroma.py` + `RagProject/`

### 9. RAG 知识库检索
- 将知识库接入 path_agent（检索经典学习路径）
- 接入 resource_agent（检索参考资料辅助生成）
- 接入 error_sim_agent（检索常见错误案例）
- **参考**：自学项目 `RagProject/rag.py`

### 10. 工具扩展（Function Calling）
- `generate_mindmap(topic) → mermaid 格式字符串`
- `search_knowledge(query) → 知识库片段`
- `generate_exercise(knowledge_point, difficulty) → 习题`
- 绑定到对应 Agent 的 LLM

## 开发建议

```
现在 → 把 6 个 Agent stub 逐个填完（每 1-2 天一个）
         ↓ 优先 path_agent（最简单）→ resource_agent（最加分）
         ↓
第2步 → ChromaDB 群体记忆 + RAG 接入（复用自学项目代码）
         ↓
第3步 → 工具扩展 + 前端对接
         ↓
第4步 → 整体调试 + 文档撰写
```

关键原则：**先让流水线跑通，再优化细节**。每个 Agent 写完能独立 `__main__` 测试即可，不追求一步到位。
