### 1. LLM 对接

**你会的（`itheima/api-use.py`）：**

```python
from openai import OpenAI

client = OpenAI(base_url="https://dashscope.aliyuncs.com/compatible-mode/v1")
response = client.chat.completions.create(
    model="qwen3-max",
    messages=[...],
    stream=True
)
for chunk in response:
    print(chunk.choices[0].delta.content, end="")
```

**比赛项目要做的（每个 Agent 都要调 LLM）：**

比赛的配置里已经预留了讯飞星火的 API 密钥字段（`config.py` 的 `SPARK_API_KEY` 等），但你可以选择：

- **方案 A（推荐）**：沿用你熟悉的阿里通义 `qwen3-max`，用 OpenAI 兼容接口
- **方案 B**：用讯飞星火（比赛要求），参考 `LangGraph/graph06.py` 中的 `ChatSparkLLM`

无论选哪个，核心调用模式不变：


### 2. LangGraph 状态定义 → `core/state.py`

**你会的（`LangGraph/graph01.py`）：**

```python
from typing_extensions import TypedDict
from langgraph.graph import StateGraph

class State(TypedDict):
    messages: list[AnyMessage]
    extra_field: int

def node(state: State) -> dict:
    return {"messages": [...], "extra_field": state["extra_field"] + 1}
```

**比赛项目已定义的（`core/state.py`）：**

```python
class LearningState(TypedDict):
    student_id: str
    profile: Optional[StudentProfile]
    message: str
    current_agent: Optional[str]
    knowledge_point: Optional[str]
    learning_path: Optional[List[dict]]
    generated_resources: Annotated[List[Resource], lambda a, b: a + b]  # 归约器
    teaching_decisions: Annotated[List[TeachingDecision], lambda a, b: a + b]
    interaction_pattern: Optional[dict]
    response: Optional[str]
```

**要点**：
- `Annotated[list, lambda a, b: a + b]` 就是你学过的归约器（`graph05.py`），多个节点返回的列表会自动合并
- 每个 Agent 函数接收 `LearningState`，返回 `dict` 更新状态中的字段

```python
from langgraph.types import Send

def resource_agent(state: LearningState) -> dict:
    """先用 Map 分派任务，再用 Reduce 汇总"""
    # 主节点：确定要生成哪些类型
    return {"resource_types": ["document", "mindmap", "exercise", "code_example", ...]}

def send_to_generators(state: LearningState):
    """Map：并行派发"""
    return [Send("single_resource_gen", {"type": t, ...}) for t in state["resource_types"]]

def single_resource_gen(state: dict) -> dict:
    """单个资源生成（调 LLM）"""
    llm_result = call_llm(...)
    return {"generated_resources": [Resource(...)]}

def collect_resources(state: LearningState) -> dict:
    """Reduce：汇总"""
```

这就是你学过的 `map_reduce.py` 的 `Send()` 模式！

## 开发路线建议

按依赖关系排序：

```
第1步：LLM 对接
  └── 配置 API Key，封装调用函数，验证通顺
第2步：Profile Agent（画像构建）
  └── 最简单的 Agent：消息 → LLM 抽取画像 → 更新状态
第3步：Path Agent（路径规划）
  └── 画像 → LLM 规划学习路径
第4步：Resource Agent（资源生成 + Map-Reduce）
  └── 并行生成多种资源（你会的 Send() 模式）
第5步：ChromaDB 群体记忆
  └── 向量存储 + 检索（你会的 chroma.py）
第6步：Error Sim Agent（错误模拟）
第7步：Buddy Agent（虚拟学伴）
第8步：Curiosity Agent（好奇心检测 + 条件路由）
第9步：Reflection Agent（后悔机制 + 循环回退）
第10步：流式输出对接前端 SSE
```
