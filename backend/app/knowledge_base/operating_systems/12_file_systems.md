# 文件系统

## 基本概念

### 文件系统是什么？

文件系统是对**持久化存储**的系统抽象——组织、控制、导航、访问和检索磁盘上的数据。

### 文件

文件是文件系统中的基本单元，是相关数据在 OS 中的抽象。

**文件属性**：名称、类型、位置、大小、保护权限、创建/修改时间等

**文件头 (File Header / Inode)**：存储文件元数据，记录文件属性和数据块位置。

### 文件系统的功能

```
文件系统
├── 空间管理
│   ├── 分配文件磁盘空间
│   ├── 管理空闲空间
│   └── 分配策略
├── 文件集合管理
│   ├── 命名与定位
│   ├── 目录结构（层次化）
│   └── 文件类型
└── 便利特性
    ├── 访问控制（保护）
    └── 可靠性与持久性
```

## 文件访问

### 打开-读/写-关闭 模式

```c
int fd = open("data.txt", O_RDONLY);
read(fd, buffer, 1024);
close(fd);
```

内核为每个进程维护**打开文件表**，文件描述符 (fd) 是表中的索引。

### 打开文件的数据结构

| 字段 | 含义 |
|:---|:---|
| 文件指针 | 当前读写位置 |
| 打开计数 | 引用计数，为 0 时可关闭 |
| 磁盘位置 | 缓存的访问信息 |
| 访问权限 | 读/写/执行模式 |

### 访问方式

| 方式 | 说明 |
|:---|:---|
| 顺序访问 | 按字节依次读写（最常见） |
| 随机访问 | 从任意位置读写（数据库、虚拟内存） |
| 索引访问 | 通过索引结构访问（数据库） |

### 用户视图 vs 系统视图

- **用户视角**：文件是字节流或记录序列
- **系统视角**：文件是**块 (Block)** 的集合（UNIX 块大小通常 4KB）

即使 `getc()` 只读 1 字节，OS 也会缓存整个 4KB 块。

## 目录

目录是一种特殊文件，包含 `(文件名 → 文件头指针)` 的映射表。

### 层次目录结构

```
/                           ← 根目录
├── bin/
│   └── ls
├── home/
│   └── user/
│       └── doc.txt
└── etc/
    └── passwd
```

### 路径解析

解析 `/bin/ls` 的过程：
1. 读取根目录的文件头（磁盘固定位置）
2. 在根目录数据块中搜索 `bin`
3. 读取 `bin` 的文件头
4. 在 `bin` 数据块中搜索 `ls`
5. 读取 `ls` 的文件头 → 找到文件

**当前工作目录 (CWD)**：每个进程有一个 CWD，支持相对路径。

### 文件别名

| 类型 | 机制 | 特点 |
|:---|:---|:---|
| 硬链接 | 多个目录项指向同一 inode | 删除一个不影响其他 |
| 软链接 | 存储目标文件路径 | 目标删除后成为悬空指针 |

## 文件分配方式

| 方式 | 原理 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 连续分配 | 文件占连续块 | 顺序/随机访问快 | 外部碎片，文件增长困难 |
| 链式分配 | 块通过指针链接 | 无碎片，易扩展 | 无法随机访问，指针开销 |
| 索引分配 | 索引块存指针列表 | 支持随机访问，易扩展 | 小文件索引开销大 |

**Unix inode** 就是索引分配——inode 中包含直接指针、一级间接、二级间接指针。

## 空闲空间管理

用**位图 (Bitmap)** 标记每个块是否空闲：

```
11111101101110111
  ↑ i=0 表示块 i 空闲，i=1 表示已分配
```

160GB 磁盘 → 40M 块 → 位图约 5MB

## 虚拟文件系统 (VFS)

```
┌─────────────────────┐
│  应用 API (open/read)│
├─────────────────────┤
│  VFS（统一接口）      │
├──────┬──────┬───────┤
│ ext4 │ NTFS │ FAT32 │  ← 具体文件系统
└──────┴──────┴───────┘
```

VFS 提供统一接口，屏蔽不同文件系统的差异。

### 核心数据结构

| 结构 | 数量 | 内容 |
|:---|:---|:---|
| 超级块 (Superblock) | 每文件系统一个 | 块大小、空闲块数等 |
| Inode (FCB) | 每文件一个 | 权限、大小、数据块指针 |
| Dentry | 每目录项一个 | 文件名 → inode 映射 |

## 磁盘调度

磁盘访问时间 = **寻道时间** + **旋转延迟** + **传输时间**

寻道时间是主要性能瓶颈。

| 算法 | 策略 |
|:---|:---|
| FCFS | 按请求顺序，公平但性能差 |
| SSTF | 选离磁头最近的请求 |
| SCAN（电梯） | 一个方向扫描到底再反转 |
| C-SCAN | 只在一个方向扫描，到头快速返回 |

## RAID

**冗余磁盘阵列**——用多块磁盘提高吞吐量和可靠性。

| 级别 | 策略 | 特点 |
|:---|:---|:---|
| RAID-0 | 条带化，无冗余 | 带宽翻倍，无容错 |
| RAID-1 | 镜像 | 可靠性翻倍 |
| RAID-4 | 块级条带 + 专用校验盘 | 可恢复一个磁盘故障 |
| RAID-5 | 分布式校验 | 一个磁盘容错，无专用校验盘 |
| RAID-6 | 双重校验 | 两个磁盘容错 |

## 学习要点总结

1. 文件系统管理持久化数据的组织、命名、访问和保护
2. 目录提供层次化命名空间，路径解析是从根到叶子的查找过程
3. 连续/链式/索引分配各有优劣，现代系统多用索引（inode）
4. VFS 抽象不同文件系统，提供统一 API
5. 磁盘调度算法优化 I/O 性能，RAID 用冗余换可靠性
