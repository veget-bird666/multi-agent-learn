# 操作系统概述

## 操作系统是什么？

从两个视角理解操作系统：

**用户视角**：操作系统是一个**控制软件**
- 管理应用程序
- 为应用程序提供服务
- 终止异常应用程序

**程序视角**：操作系统是**资源管理器**
- 管理外设、分配资源
- 通过抽象简化硬件使用：
  - 将 CPU 抽象成**进程**
  - 将磁盘抽象成**文件**
  - 将内存抽象成**地址空间**

## 操作系统在计算机中的位置

```
┌─────────────────────────────┐
│      应用程序 (Apps)         │
├─────────────────────────────┤
│   Shell（界面：Linux/Windows）│  ← 用户交互外壳
├─────────────────────────────┤
│      内核 Kernel             │  ← 操作系统研究的核心
├─────────────────────────────┤
│      硬件 (Hardware)         │
└─────────────────────────────┘
```

Linux、Windows、Android 的图形界面属于 **Shell（外壳）**，不是内核。操作系统课程主要研究**内核**——位于 Shell 之下、硬件之上的核心层。

## 内核的主要组件

| 组件 | 职责 |
|:---|:---|
| CPU 调度器 | 决定哪个进程占用 CPU |
| 物理内存管理 | 分配和回收物理内存 |
| 虚拟内存管理 | 提供比物理内存更大的地址空间 |
| 文件系统管理 | 组织持久化数据的存储与访问 |
| 中断处理与设备驱动 | 响应硬件事件，控制外设 |

## 操作系统的四大特征

### 1. 并发 (Concurrency)

一段时间内运行多个进程。**并行**则指同一时刻多个进程真正同时运行（通常需要多核 CPU）。

并发需要 OS 进行管理和调度，否则多个程序会互相干扰。

### 2. 共享 (Sharing)

两种共享方式：
- **同时访问**：如只读代码段，多个进程可同时读取
- **互斥访问**：如写文件，同一时刻只允许一个进程修改

### 3. 虚拟 (Virtualization)

让每个用户感觉拥有一台专属于自己的计算机。例如：多个用户同时登录一台 Linux 服务器，各自拥有独立的进程空间和文件视图。

### 4. 异步 (Asynchrony)

程序的执行不是连续不断的，而是走走停停——等待 I/O、被调度器抢占、响应中断等。OS 必须在不确定的事件顺序下保证系统正确运行。

## 操作系统 vs 普通程序

| 对比项 | 普通应用程序 | 操作系统 |
|:---|:---|:---|
| 运行位置 | 用户态 | 内核态 + 用户态 |
| 权限 | 受限，不能直接操作硬件 | 可执行特权指令 |
| 生命周期 | 由 OS 创建和销毁 | 随系统启动而运行 |
| 目标 | 完成特定任务 | 管理资源和调度程序 |

## 学习要点总结

1. 操作系统是硬件之上的资源管理者，为应用程序提供抽象和服务
2. Shell 是用户界面，内核才是 OS 的核心
3. 四大特征——并发、共享、虚拟、异步——贯穿整个 OS 设计
4. 并发 ≠ 并行：并发是逻辑上的同时，并行是物理上的同时
5. 理解 OS 的层次结构，是后续学习进程、内存、文件系统的基础
