# C语言指针详解

## 什么是指针

指针是C语言中一种特殊的变量，它**存储的是内存地址**，而不是普通的值。每个变量在内存中都有一个地址，指针变量就是用来存放这个地址的。

### 指针的声明

```c
int *p;      // p 是一个指向 int 类型变量的指针
char *cp;    // cp 是一个指向 char 类型变量的指针
double *dp;  // dp 是一个指向 double 类型变量的指针
```

这里的 `*` 表示"这是一个指针"。

### 取地址符 & 和解引用符 *

- **&**：取地址运算符，获取变量的内存地址
- **\***：解引用运算符，通过指针访问指向的变量

```c
int a = 10;
int *p = &a;   // p 保存了变量 a 的地址
printf("%d", *p);  // 输出 10，*p 等价于 a
```

## 指针的核心概念

### 指针与内存

理解指针的关键是理解内存模型。内存可以看作一个大型数组，每个字节都有一个唯一的地址编号。

- 指针变量本身也有地址（指针的指针）
- 指针的大小在32位系统上是4字节，64位系统上是8字节

### 空指针与野指针

```c
int *p = NULL;  // 空指针，指向地址 0，表示指针未指向有效内存
int *q;         // 野指针（未初始化），指向随机地址，极其危险！
```

**黄金规则**：指针声明时必须初始化，要么赋值为有效地址，要么赋值为 NULL。

## 指针的运算

### 指针算术

指针支持有限的算术运算，结果取决于指针指向的数据类型大小：

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;      // p 指向 arr[0]

p++;               // p 指向 arr[1]（地址增加 4 字节，因为 int 是 4 字节）
*(p + 2)           // 等价于 arr[3]，即 40
```

### 指针与数组

数组名在大部分表达式中退化为指向首元素的指针：

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;          // 等价于 int *p = &arr[0]
arr[2] == *(arr + 2);  // 永远为 true
```

**重要区别**：`sizeof(arr)` 返回整个数组的大小（20字节），而 `sizeof(p)` 返回指针的大小（8字节）。

## 指针的高级应用

### 指针作为函数参数

指针可以实现"传引用"效果，在函数内部修改外部变量：

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int x = 5, y = 10;
swap(&x, &y);  // 调用后 x=10, y=5
```

### 指针与字符串

字符串字面量在C语言中是字符数组，其类型为 `char *`：

```c
char *s = "Hello";       // s 指向字符串常量
char arr[] = "Hello";    // arr 是字符数组，内容可修改
```

`s` 指向的字符串常量**不可修改**，而 `arr` 的内容可以修改。这是初学者最容易犯的错误之一。

### 函数指针

函数也有地址，可以声明指针指向函数：

```c
int add(int a, int b) { return a + b; }
int (*func_ptr)(int, int) = add;
int result = func_ptr(3, 4);  // 输出 7
```

函数指针常用于回调机制，是实现C语言高级抽象的重要工具。

## 常见错误与调试技巧

### 段错误（Segmentation Fault）

最常见的指针错误，原因包括：
1. **解引用空指针**：`*NULL`
2. **解引用野指针**：未初始化就使用
3. **数组越界**：`arr[100]` 但数组只有10个元素
4. **栈上变量返回指针**：函数返回局部变量的地址

### 内存泄漏

使用 `malloc` 分配的内存必须用 `free` 释放：
```c
int *p = (int *)malloc(sizeof(int) * 10);
// 使用 p...
free(p);      // 忘记这行会导致内存泄漏
p = NULL;     // 避免野指针
```

## 学习要点总结

1. 指针保存的是地址，不是值
2. 声明时的 `*` 和使用的 `*` 含义不同：声明时表示"这是一个指针"，使用时表示"解引用"
3. 指针算术的单位是"指向类型的大小"，不是字节
4. 指针必须初始化！NULL 是安全的初始值
5. 动态分配的内存必须配对 free
6. 数组名在大多数情况下等价于指向首元素的指针
