# C语言运算符与表达式

## 运算符优先级与结合性

C语言有45个运算符，优先级规则复杂。不要依赖记忆，**始终使用括号**。

### 优先级速查表（从高到低）

| 优先级 | 运算符 | 结合性 | 说明 |
|:---|:---|:---|:---|
| 1 | `()` `[]` `->` `.` | 左到右 | 函数调用、数组下标、成员访问 |
| 2 | `++` `--` (后缀) | 左到右 | 先使用，后增减 |
| 2 | `++` `--` (前缀) `+` `-` `!` `~` `*` `&` `sizeof` | 右到左 | 先增减/取反/解引用 |
| 3 | `*` `/` `%` | 左到右 | 乘除模 |
| 4 | `+` `-` | 左到右 | 加减 |
| 5 | `<<` `>>` | 左到右 | 位移 |
| 6 | `<` `<=` `>` `>=` | 左到右 | 关系比较 |
| 7 | `==` `!=` | 左到右 | 相等比较 |
| 8 | `&` | 左到右 | 按位与 |
| 9 | `^` | 左到右 | 按位异或 |
| 10 | `\|` | 左到右 | 按位或 |
| 11 | `&&` | 左到右 | 逻辑与（短路求值） |
| 12 | `\|\|` | 左到右 | 逻辑或（短路求值） |
| 13 | `?:` | 右到左 | 条件运算符 |
| 14 | `=` `+=` `-=` 等 | 右到左 | 赋值 |
| 15 | `,` | 左到右 | 逗号运算符 |

### 经典优先级陷阱

```c
int a = 5, b = 3;
int c = a & b == 1;   // 等价于 a & (b == 1)，不是 (a & b) == 1

int *p = NULL;
if (!p == 0) {        // 等价于 (!p) == 0，即 1 == 0，为假
    // 不会执行
}
```

## 自增自减运算符

### 前缀 vs 后缀

```c
int a = 5;
int b = ++a;   // a 先变成 6，然后 b = 6
int c = a++;   // c 先得到 6，然后 a 变成 7
```

**关键区别**：前缀返回**修改后的值**，后缀返回**修改前的值**。后缀需要保存旧值，理论上效率略低（现代编译器通常优化掉）。

### 未定义行为

```c
int i = 0;
int a = i++ + i++;   // 未定义行为！同一变量在两个序列点间被修改两次

int arr[5] = {1,2,3,4,5};
int x = arr[i++] + arr[i++];  // 未定义行为！
```

**序列点**：程序执行到某个点时，之前的所有副作用必须完成。主要序列点包括：
- 完整表达式结束（语句末尾的分号）
- `&&`、`||`、`?:`、逗号运算符的左操作数之后
- 函数调用前（参数求值完成后）

## 赋值运算符

### 连续赋值

```c
int a, b, c;
a = b = c = 0;   // 从右到左：c=0, b=c(0), a=b(0)
```

### 复合赋值

```c
a += b;   // 等价于 a = a + b，但 a 只计算一次
a *= b + c;  // 等价于 a = a * (b + c)，不是 (a * b) + c
```

## 条件运算符（三目运算符）

```c
int max = (a > b) ? a : b;
```

**注意**：三目运算符的两个分支类型必须兼容，否则会发生隐式转换：

```c
int a = 5;
double b = 3.14;
auto result = (a > 3) ? a : b;   // result 类型为 double，a 被提升
```

## 逗号运算符

```c
int a = (1, 2, 3);   // a = 3，逗号运算符返回最后一个表达式的值

for (int i = 0, j = 10; i < j; i++, j--) {
    // 逗号在 for 循环中很常见
}
```

**注意**：`int a = 1, 2, 3;` 是声明语句，不是逗号运算符！等价于 `int a = 1; int 2; int 3;`（编译错误）。

## 类型转换规则

### 整数提升

在表达式中，`char`、`short`、`bool`（C99）、位域等会先提升为 `int`（如果 `int` 能表示其范围）或 `unsigned int`。

```c
unsigned char a = 255;
unsigned char b = 1;
unsigned char c = a + b;   // a 和 b 先提升为 int，相加得 256，截断为 0
```

### 算术转换（寻常算术转换）

当不同类型的操作数混合时，按以下规则转换：

```
long double
    ↑ double
        ↑ float
            ↑ unsigned long long
                ↑ long long
                    ↑ unsigned long
                        ↑ long
                            ↑ unsigned int
                                ↑ int
```

**有符号和无符号的陷阱**：

```c
long a = -1;
unsigned int b = 1;
if (a < b) {
    printf("-1 < 1\n");
} else {
    printf("-1 >= 1 ???\n");  // 输出这行！
}
```

原因：`unsigned int` 和 `long` 长度相同时，`long` 被转为 `unsigned long`，`-1` 变成最大值。

## 表达式求值顺序

C语言**不规定**大多数运算符的操作数求值顺序：

```c
int func1() { printf("1"); return 1; }
int func2() { printf("2"); return 2; }
int result = func1() + func2();   // 可能输出 "12" 或 "21"，未指定
```

**例外**（保证顺序）：`&&`、`||`、`?:`、逗号运算符。

```c
if (func1() && func2()) { }   // 如果 func1 返回 0，func2 不会执行（短路）
```

## 学习要点总结

1. 不要依赖运算符优先级，复杂表达式用括号明确意图
2. 同一变量在序列点之间被修改两次是未定义行为
3. 有符号和无符号混合运算时，有符号会被转为无符号
4. 大多数运算符不保证操作数求值顺序
5. `&&` 和 `||` 具有短路特性，常用于条件判断和防御式编程
