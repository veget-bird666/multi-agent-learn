# C语言数据类型与变量

## 数据类型的本质

C语言是**强类型静态语言**。每个变量在编译时就必须确定类型，因为类型决定了：
- **内存占用大小**：`int` 占4字节，`double` 占8字节
- **存储方式**：整数用补码，浮点数用 IEEE 754
- **合法操作**：不能对 `int` 做字符串拼接
- **解释方式**：同样的二进制 `0x40400000`，作为 `int` 是 1077936128，作为 `float` 是 3.0

## 基本数据类型

### 整数类型家族

| 类型 | 最小范围 | 典型大小 | 格式符 |
|:---|:---|:---|:---|
| `char` | -128 ~ 127 | 1字节 | `%c` 或 `%d` |
| `short` | -32768 ~ 32767 | 2字节 | `%hd` |
| `int` | -2147483648 ~ 2147483647 | 4字节 | `%d` |
| `long` | 至少与 `int` 相同 | 4或8字节 | `%ld` |
| `long long` | -9×10¹⁸ ~ 9×10¹⁸ | 8字节 | `%lld` |

**有符号 vs 无符号**：

```c
unsigned int u = 4000000000;  // 可以存储更大的正数
signed int s = -100;          // 可以存储负数
```

`unsigned` 的最高位不表示符号，而是数值位。一个经典陷阱：

```c
unsigned int u = 10;
int s = -1;
if (s < u) {
    printf("-1 < 10\n");
} else {
    printf("-1 >= 10 ???\n");  // 实际输出这行！
}
```

**原因**：`s` 被提升为 `unsigned int`，`-1` 的二进制表示 `0xFFFFFFFF` 被解释为 4294967295。

### 浮点类型

| 类型 | 精度 | 典型大小 | 有效数字 |
|:---|:---|:---|:---|
| `float` | 单精度 | 4字节 | 6-7位 |
| `double` | 双精度 | 8字节 | 15-16位 |
| `long double` | 扩展精度 | 12/16字节 | 18-21位 |

**浮点数陷阱**：

```c
if (0.1 + 0.2 == 0.3) {
    printf("相等\n");
} else {
    printf("不相等！\n");  // 输出这行
}
```

因为 `0.1` 在二进制中是无限循环小数，存储时截断导致精度损失。正确做法：

```c
#include <math.h>
if (fabs(0.1 + 0.2 - 0.3) < 1e-9) {
    printf("近似相等\n");
}
```

### 字符类型

```c
char c = 'A';        // 存储的是 ASCII 码 65
char d = 65;         // 与上面等价
printf("%c", c);     // 输出 A
printf("%d", c);     // 输出 65
```

**转义字符**：

| 转义序列 | 含义 | 转义序列 | 含义 |
|:---|:---|:---|:---|
| `\n` | 换行 | `\t` | 水平制表 |
| `\r` | 回车 | `\\` | 反斜杠 |
| `\'` | 单引号 | `\"` | 双引号 |
| `\0` | 空字符 | `\x41` | 十六进制表示的A |

## 变量的声明与定义

### 声明 vs 定义

```c
extern int x;      // 纯声明：告诉编译器 "x 在其他地方定义了"
int x = 10;        // 定义：分配内存并初始化
```

**规则**：变量只能被**定义**一次，但可以被**声明**多次。

### 初始化 vs 赋值

```c
int a = 10;        // 初始化：定义时给值
int b;
b = 20;            // 赋值：定义后给值
```

**未初始化的局部变量值是垃圾**：

```c
int x;
printf("%d\n", x);  // 未定义行为！可能是任意值
```

全局变量和静态变量会被自动初始化为0，但局部变量不会。

### 常量

```c
const int MAX = 100;       // 只读变量，编译时常量（C99前不完全）
#define MAX 100            // 宏常量，纯文本替换
enum { SIZE = 256 };       // 枚举常量，真正的编译时常量
```

**`const` 的陷阱**：

```c
const int a = 10;
int *p = &a;        // 警告：丢弃 const 限定
*p = 20;            // 未定义行为！可能崩溃或无效
```

`const` 只是编译器的约束，通过指针可以绕过（但不要这么做）。

## 类型转换

### 隐式转换（自动提升）

C语言在表达式中会自动进行**整数提升**和**算术转换**：

```c
char c = 'A';
int i = c + 1;     // c 先提升为 int，然后相加

int a = 5;
double d = a / 2;  // 结果是 2.0，不是 2.5！整数除法截断
```

**整数除法陷阱**：两个整数相除结果还是整数，小数部分直接丢弃（不是四舍五入）。

### 显式转换（强制类型转换）

```c
double d = (double)5 / 2;  // 结果是 2.5
```

**危险转换**：

```c
int *p = malloc(sizeof(int));
short *s = (short *)p;     // 可能破坏内存对齐
*s = 1;
```

## sizeof 运算符

`sizeof` 是**编译时运算符**，不是函数：

```c
int arr[10];
printf("%zu\n", sizeof(arr));       // 40（整个数组）
printf("%zu\n", sizeof(arr[0]));     // 4（单个元素）
printf("%zu\n", sizeof(arr) / sizeof(arr[0]));  // 10（元素个数）

// 但在函数参数中数组退化为指针
void func(int arr[]) {
    printf("%zu\n", sizeof(arr));   // 8（指针大小）
}
```

## 学习要点总结

1. 类型决定内存大小、存储方式和解释方式
2. `unsigned` 和 `signed` 混合运算时，`signed` 会被提升为 `unsigned`
3. 浮点数不能直接用 `==` 比较，应判断差值是否小于阈值
4. 局部变量必须初始化，否则值不确定
5. `sizeof` 是编译时运算符，数组作为参数会退化为指针
